# 接入问题排查

| 现象 | 先检查 |
|---|---|
| 401 | Key 是否完整、是否属于本站、是否启用，客户端使用哪个认证字段 |
| 403 | 账户 / Key 权限、客户端来源或安全规则；结合实际错误说明判断 |
| 404 / 路径不存在 | 最终 URL 是否重复 `/v1`，当前模型是否支持该路径 |
| 模型不存在 / 无权访问 | 模型 ID、大小写、别名与 Key 的模型范围 |
| 余额或额度不足 | 余额、正在占用的预留额度、Key / 账户限额 |
| 429 | 当前限流信息与 `Retry-After`，避免并发立即重试 |
| 5xx / 超时 | 时间、请求关联 ID、客户端超时、服务状态及调用记录 |
| 图片不支持 | 客户端能力声明、实际模型视觉能力、请求格式及协议 |
| 流有文字但最后报错 | 结束事件、usage 是否完整、网络中断与调用记录；不要只看 HTTP 200 |
| 价格或 usage 不一致 | 输入 / 输出 / 缓存 / 模态分类、时段及账单规则，不用字符数直接换算 |

HTTP 状态码只是排查入口，实际原因应结合返回的错误类型和请求记录确认。

## 提交问题时提供什么

- 使用的客户端及版本、模型 ID、接口类型。
- 大致时间和时区、HTTP 状态及经过脱敏的错误原文。
- 返回的 `X-302API-Request-ID`（如有）。
- 能复现问题的最小示例，移除私人提示词、文件、邮箱和其他用户数据。

**不要公开 API Key、Authorization 请求头、Cookie、验证码、账单截图中的个人信息或完整客户请求。** 安全问题按 [SECURITY.md](../SECURITY.md) 私密报告；个人账户问题使用官网当前公开的支持渠道，不要把账户资料发到公开 Issue。
