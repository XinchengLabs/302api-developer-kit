# Cherry Studio

在设置中的模型服务 / 提供商配置一个 OpenAI 兼容服务：

| 字段 | 值 |
|---|---|
| 名称 | 302API |
| API Key | 在客户端的安全配置中填写自己的 Key |
| API 地址 / Base URL | `https://api.302api.com/v1` |
| 模型 ID | 当前 Key 可用的实际模型 ID，保持大小写一致 |

不同版本对地址补全的处理可能不同。确认最终请求为 `https://api.302api.com/v1/chat/completions`，避免出现重复 `/v1/v1`。如果当前版本的地址提示要求填写根域名，则按照该版本提示配置，仍以最终请求路径为准。

选择模型后再发送一条短文本，确认响应及账单。模型是否支持图片、工具调用或特定参数，需要分别确认；添加自定义模型名不会自动赋予模型这些能力。

不导入来源不明的完整客户端配置，不在截图、日志或 Issue 中暴露 Key。
